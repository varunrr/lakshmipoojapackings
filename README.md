# Lakshmi Pooja Packings

A lightweight, single-page brand site for Lakshmi Pooja Packings, a corrugated box manufacturer in Coimbatore.

## Preview locally

No installation or build step is required.

```sh
python3 -m http.server 8080
```

Then open `http://localhost:8080`.

## Structure

- `index.html` — site content, metadata and structured business data
- `css/style.css` — custom responsive visual system
- `js/main.js` — mobile navigation, reveal effects and WhatsApp quote flow
- `img/brand/` — optimized site photography

The quote form has no server dependency. It formats the submitted details and opens a WhatsApp conversation with the business.

## Before publishing

The two workshop photographs in `img/brand/` are generated design assets, not documentary photos of the Lakshmi Pooja Packings facility. Replace them with verified factory and product photography when available.
